## Entry

`main.ts` (Node 22, stdlib only) writes one single-line joke about office life to `/output/entry.txt`: 1–200 characters, one line, no trailing newline, deterministic across runs.

## The joke

A specific, recognisable office detail — the meeting that should have been an email, the reply-all, the standup that never moves — with the punchline landing at the end. The judge weighs, in order: a real one-line office joke, funniness (surprise payoff anyone who has sat in an office recognises), one line, freshness (a specific detail, not a generic complaint), and clarity on first read.

## Run

```sh
node main.ts
cat /output/entry.txt
```
